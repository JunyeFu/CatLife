# 双端视觉修复方案与增量开发控制

日期：2026-11-06。状态：**三项产品取舍已确认；G0、G1已通过，下一项WP06.7.1。实装在独立分支，尚无新APK，G2–G4未通过。** [基础交付](2026-11-06-ui-style-foundation.md) · [静态UI实测](2026-11-06-ui-static-results.md)。

依据：[十条双端自查](../audits/2026-11-06-ui-design-self-review.md)。沿用 C06/WP06（软件视觉）、C07/WP07（同包验证）、C08/WP08（GitHub 展示）及原 S 任务，不新增完成率或状态库。用户本轮指令优先于旧比赛排期；本计划不恢复已清除的旧目标。

## 1. 已确认的产品决策

用户本轮已逐项选择：

1. 中性色用于 UI 面板、卡片和输入框；橙绿保留为品牌强调。仅处理现有暗底区域，不新增全局暗色模式开关；猫、小镇和按钮位置不变。
2. AI 完整结果返回后在本地逐字显现；不改网络接口为流式，保持会后单次请求。
3. 结束条采用 1200/80 弹簧；**可见滑块进度统一驱动填充、猫爪接触和松手 65% 判定**，不另设一份抢先触发的逻辑进度。

这些确认不等于新 UI 的真实画面、字体或动画已经验收。

## 2. 冻结范围与工程口径

| 控制项 | 本轮规则 |
|---|---|
| 视觉范围 | 只改 UI 色层、皮肤、输入聚焦、字形/排版和指定文字/手势动效。七页、按钮数量/位置、48dp 点击区域、安全区、完整空岛、猫和小镇贴图、已接受动作、摄像机及世界颜色保持。专注天空不当成 UI 底板重涂。 |
| 业务边界 | 保留唯一 Session、存储键、记录格式、计时截止、奖励、AI 同意/单次请求/失败不重试。无 SSE、新后端、重试队列、通用主题框架或全项目 TMP/UI Toolkit 迁移。 |
| 参数主源 | 实施时建立一个小型 `Assets/MobileRuntime/UI/Style/CL_UI_StyleTokens.json`，由现有皮肤导出器、Editor 安装器和展示图渲染器读取。运行时只消费已序列化颜色/字体/参数，不新增配置加载或主题服务。网页 CSS token 为生成产物。 |
| 颜色口径 | 浅底 `#f5f5f3`，卡片 `#fcfcfb`；暗底 `#0b0b0a`，内容面 `#151515/#1a1a19/#20201e`；普通深字用 `#20201e`，亮字用 `#fcfcfb`。品牌色限强调。常态容器不加硬描边，聚焦采用内阴影双环。 |
| 明度口径 | 1%–3%针对相邻**内容容器层**的 HSL 明度差。给定暗根底到首内容面约差4.1个百分点，保留给定色值并明确为根底例外，不伪称所有相邻色都在1%–3%。不以低层差代替文字可读性。 |
| 单位 | Spring 质量为1，时间为秒，轨道进度为0–1。字显90ms、间隔30ms；软件blur半径6个设计坐标px，随Canvas缩放，参考宽1080；网页仅真正行内图标使用-0.125em。 |
| 开发隔离 | 保留当前 main 脏树和 r41/MVP；实现使用独立任务分支/源码工作区，验证复用 F盘已还原Unity工程，不复制Library。每次只允许一个Editor及一个Prefab写入者；原始美术只读。 |
| 候选与凭据 | 新建独立 r42 UI 候选，包名 `com.catlife.review.uistyle`，版本沿用0.3.0/code3，独立输出，不覆盖 `.ui` 或MVP。默认构建不带凭据、不开AI。无凭据也不改变Meshy资产私有交付范围，APK不作为GitHub附件。 |

色值主源、变更白名单与本轮测试需求是当前十条规范的消费者，不扩成额外配置框架。透明像素、字体alpha遮罩及3D世界阴影不按可见UI纯黑误判；Image的白色乘色也不等于最终表面色。

## 3. 关键实现约束

### 字重与排版

- 软件当前计时器/FocusTitle绑定的 Noto Medium 实际字重为500；暗底目标应为**460**，不是把Normal标签写成360。现有变量子集有100–900的wght轴且覆盖固定Focus HUD，可用fontTools导出静态460实例，维持uGUI Text。只为实际暗底文字配置资源，其他字重不顺手重做。
- `CatLifeMobileApp`初始化会统一覆盖所有Text字体；实施时必须让暗底角色绑定在该步骤之后生效。不能只改Editor字体，启动后又被覆盖。字体/普通文字颜色的运行时重赋值（如准备页切换）也必须消费新token。
- 原变量子集缺主页文案所需的63个字符，也缺补充暗底角色所需字形；WP06.6已从官方完整Noto源裁切四个暗底角色的460实例。网页再按固定文案生成轻量可变字库并保留OFL；原大字库放本地输入，不随APP/主页重复带入。网页暗区正文400→360、标题700→660等逐角色减40，实际字体须支持该轴。
- 软件数字字体原本等宽；新增460实例仍检查0–9 advance一致及00:00、01:11、08:08、09:59、10:00的显示。网页设置`font-variant-numeric: tabular-nums`。
- 网页正文使用`text-wrap: pretty`。软件固定文案以真实宽度校正换行；动态正文仅在末行单字时做一次显示层断行调整，保留字号和存档原串，完整测量后滚动展示，不截字、不烘焙动态文本。

### 会后逐字清晰化

- 只作用于会后建议正文；来源标签、时长、奖励和计时数字即时显示。AI成功或本地洞察均可用同一展示组件验收，但来源必须真实；请求中占位不做打字动画。
- 完整文本先保存并完成全量排版，content高度只按完整文本测一次。逐字效果只改变绘制，避免内容高度、滚动和按钮位置随显现抖动。
- 以文本元素为边界处理显示顺序，不拆UTF-16代理对；非空白第i字起点为`t0+i×30ms`，随后90ms内blur从6降到0，曲线为`cubic-bezier(.215,.61,.355,1)`。未轮到的字不显示；空白/换行不单独占一个节拍。
- 同一会话记录引用与同一正文重复Render不能重播；离页/后台/清除/销毁立即结束显示任务；重返已展示结果直接完整显示。去重状态只在表现组件内，不给存档加动画字段。不得改存档内容、重新请求、抢回页面或延迟奖励/猫咪动作。
- 首选保持现有Text，采用`BaseMeshEffect`与局部uGUI材质的候选实现。**先证明字形四边形/文本元素映射、6px真模糊、图集邻字不串色、ScrollRect/Mask裁切正确**。透明度渐入不算blur；不能以这个效果为由擅自迁移全项目字体系统。

### 单一可见拖动进度

- `CatLifeExitGesture.Progress`继续是唯一对外进度；原始指针仅作为目标/继续拖动意图。弹簧参与更新该进度，滑块、填充、提示、阶段事件和猫咪响应都消费它；不在Presenter再平滑一遍。
- 15%接近、35%接触和65%松手门槛均按此进度。准备/按住阶段维持35%约束；1.2秒从可见进度首次到35%进入Preparing计起，包含原0.4秒准备，不另加1.2秒按住。继续拖动或到上限放行时，重设原点并同步弹簧位置/速度，不瞬移补完指针差值。
- **抬手不瞬移追赶目标、不用本帧指针位置强补65%。** 以抬手前已应用于滑块的进度判定：可见64.9%/指针90%不能确认，可见65%才可确认。自然到时仍由Session优先结算一次。
- 固定目标阶跃与归位需单调无回弹；回拖、低帧率和边界不得出轨。按质量1、k=1200、c=80进行解析或稳定积分，不用不稳定的逐帧朴素Euler。失焦/后台/取消立即清手势和速度，不能迟到弹确认。
- `CatLifePawContactView`在拖动及可见回位阶段冻结轨道定位，归位结束才重新投影；否则其Idle定位可能与弹簧争写。仅处理UI接触与阶段绑定，不改骨架、动画或相机来掩盖误差。
- 380/18是点赞/对勾场景的保留参数；当前没有该交互，不新增组件。复制2.5秒自熄和Grid折叠同理：不新增不存在的功能；GitHub原生details动画仍是平台限制。

## 技术依据与尚未验证项

- [fontTools静态实例化](https://fonttools.readthedocs.io/en/latest/varLib/instancer.html)支持从变量轴生成静态字体；本地Medium为500。四角色460实例已在Unity验过，详见静态UI记录。
- [Unity FontStyle](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/FontStyle.html)提供Normal/Bold等样式，不是任意数值字重接口。
- [Unity uGUI BaseMeshEffect官方源码](https://github.com/Unity-Technologies/uGUI/blob/main/com.unity.ugui/Runtime/UGUI/UI/Core/VertexModifiers/BaseMeshEffect.cs)提供网格扩展点；“逐字blur可据此落地”是本计划的候选路线，仍必须通过WP06.7.1，不能据API存在直接宣称效果完成。
- [Google Fonts官方Noto Sans SC来源](https://github.com/google/fonts/tree/main/ofl/notosanssc)含完整变量字库与OFL。完整源仅缓存本地Assets外，运行只引用已裁切实例。
