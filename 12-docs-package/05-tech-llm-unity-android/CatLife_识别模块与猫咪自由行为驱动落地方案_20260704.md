## 2. 目标状态

下一阶段完成后，猫咪应具备以下行为能力：

| 目标 | 可验收表现 |
|---|---|
| 非专注自由行走 | 猫不被限制在摄像机可见范围内，可在小镇可行走区域内持续巡游 |
| 防穿模 | 猫不能进入建筑、树、围栏、摊位、长椅、花坛、水池等不可走区域 |
| 连续移动动画 | 移动期间持续播放 `CL_CAT_SRC_Walk_60fps`，不插入 idle，不上下跳动，不漂浮或陷地 |
| 到点行为 | 到达合法目的地后，可播放轻嗅、回头、摆尾、伸懒腰等状态动作 |
| 专注低打扰 | 专注中猫降低速度和互动频率，保留低刺激 idle/耳朵动作，不强行贴近用户 |
| 用户交互响应 | 点击、长按、切换专注状态等事件能触发可解释动作 |
| 识别驱动 | 行为系统读取结构化 `RecognitionSnapshot`，而不是直接读取隐私原始数据 |
| LLM 可接入 | LLM 只输出建议、文案和权重偏置，不能直接控制坐标、Transform 或 Animator |
| 降级可运行 | 关闭 LLM 或识别 mock 后，本地规则仍能完整驱动猫咪 |

## 3. 采用的核心路线

研究报告推荐的路线应作为当前项目的技术决策基线：

```text
非敏感识别摘要
    -> CatBehaviorDriver 行为决策
    -> CatDestinationPlanner 生成合法目的地
    -> NavMeshAgent 推动猫咪移动
    -> CatAnimationController 按速度和状态播放动画
    -> CatPromptBuilder/LLM 低频提供建议
```

具体选择：

| 问题 | 采用方案 | 原因 |
|---|---|---|
| 全场自由行走 | Unity AI Navigation / NavMesh 为主 | 能表达可走区域、路径、剩余距离和绕障 |
| 兴趣点行为 | 少量兴趣点锚点辅助 | 让猫更像在逛广场、树荫、长椅、路口，而不是纯随机 |
| 终点防穿模 | `NavMesh.SamplePosition` + `NavMesh.CalculatePath` + `Physics.OverlapSphereNonAlloc` | 路径完整性和终点局部碰撞双重校验 |
| 动画播放 | 单层 Animator Controller + 脚本 `CrossFadeInFixedTime` | 10 个动作数量可控，避免复杂 layer 和 trigger 风暴 |
| 移动与动画关系 | Animation follows agent | NavMeshAgent 控制位移，Animator 只跟随速度播放，不开 root motion 推动世界位移 |
| LLM 边界 | 结构化建议层 | LLM 不直接操作场景，只返回白名单 JSON |

## 4. 模块拆分

### 4.1 Recognition

新增目录：

```text
Assets/Scripts/Recognition/
```

推荐文件：

| 文件 | 职责 |
|---|---|
| `IRecognitionProvider.cs` | 识别输入统一接口 |
| `RecognitionSnapshot.cs` | 当前专注状态、用户意图、打扰风险、交互就绪度等结构化摘要 |
| `MockRecognitionProvider.cs` | Unity Play Mode 内可调试的本地 mock |

`RecognitionSnapshot` 只允许包含非敏感摘要：

| 字段 | 示例 |
|---|---|
| `focusState` | `NonFocus` / `Focused` / `TransitioningIn` / `TransitioningOut` |
| `userIntent` | `None` / `WantsInteraction` / `WantsQuiet` / `Busy` |
| `interruptionRisk` | `Low` / `Medium` / `High` |
| `focusConfidence` | 0 到 1 |
| `interactionReadiness` | 0 到 1 |
| `safeLocalSummary` | `focused_session_active; no raw app content` |

禁止进入 snapshot 的内容：

- 屏幕截图、录屏、OCR 内容。
- 键盘输入原文。
- 聊天、联系人、文件名、其他 App 页面内容。
- 原始触摸坐标序列。

### 4.2 Cat Behavior

新增目录：

```text
Assets/Scripts/Cat/
```

推荐文件：

| 文件 | 职责 |
|---|---|
| `CatBehaviorState.cs` | 行为枚举 |
| `CatBehaviorDriver.cs` | 唯一行为决策入口 |
| `CatDestinationPlanner.cs` | 合法目的地生成和校验 |
| `CatNavigationAgent.cs` | `NavMeshAgent` 包装、速度、到达、调试路径 |
| `CatAnimationController.cs` | Animator 参数和动作 crossfade |

`CatBehaviorDriver` 的职责边界：

- 读取 `RecognitionSnapshot`。
- 读取可选 `LLMBehaviorSuggestion`。
- 根据当前状态选择下一次行为。
- 决定是否移动、停留、播放哪个动作。
- 不直接随机改 `transform.position`。
- 不直接读取 UI 文本或隐私原始数据。

### 4.3 Prompt / LLM

新增目录：

```text
Assets/Scripts/LLM/
```

推荐文件：

| 文件 | 职责 |
|---|---|
| `CatPromptContext.cs` | 发送给模型的安全上下文 |
| `CatPromptBuilder.cs` | System/Developer/UserContext/OutputSchema 拼装 |
| `ICatLLMClient.cs` | LLM 客户端接口 |
| `LLMBehaviorSuggestion.cs` | 白名单建议 DTO |
| `MockCatLLMClient.cs` | 本地 mock，验证降级与权重偏置 |

LLM 输出只允许：

```json
{
  "suggestedLine": "我会在附近安静陪你。",
  "moodBias": "calm",
  "roamWeightBias": -0.1,
  "quietIdleWeightBias": 0.2,
  "socialResponseWeightBias": -0.12,
  "showBubble": false
}
```

Unity 端必须二次裁剪：

| 字段 | 白名单 |
|---|---|
| `suggestedLine` | 最长 48 字 |
| `moodBias` | `calm` / `curious` / `affectionate` / `alert` |
| 三个权重偏置 | `-0.35` 到 `0.35` |
| `showBubble` | 布尔值 |

## 5. Animator 与 11 个动作映射

Animator Base Layer 推荐保留这些状态名，代码用 hash 访问：

| 行为 | Animator State | 动作来源 | 触发条件 |
|---|---|---|---|
| 默认呼吸 | `Base Layer.IdleBreath` | `CL_CAT_IdleBreath_v06_headsync_loop_108f` | 默认停留、专注低刺激 |
| 连续行走 | `Base Layer.Walk` | `CL_CAT_SRC_Walk_60fps` | `NavMeshAgent.velocity` 大于阈值 |
| 警觉看 | `Base Layer.AlertLook` | `CL_CAT_AlertLook_v01_loop_120f` | 打扰风险上升、专注切换 |
| 轻嗅 | `Base Layer.CuriousSniff` | `CL_CAT_CuriousSniff_v02_loop_112f` | 非专注到点探索 |
| 耳朵警觉 | `Base Layer.EarTwitchAlert` | `CL_CAT_EarTwitchAlert_v02_loop_120f` | 专注低扰动反馈 |
| 摇头 | `Base Layer.HeadShakeNo` | `CL_CAT_HeadShakeNo_v01_loop_108f` | 过度点击、无效操作、低频反馈 |
| 歪头听 | `Base Layer.HeadTiltListen` | `CL_CAT_HeadTiltListen_v01_loop_96f` | 长按、用户想互动、文案出现 |
| 开心摆尾 | `Base Layer.TailWagHappy` | `CL_CAT_TailWagHappy_v01_loop_96f` | 奖励、点击后正反馈 |
| 伸懒腰 | `Base Layer.StretchYawn` | `CL_CAT_StretchYawn_v03_slow_loop_264f` | 非专注长 idle，低频 |
| 挥爪 | `Base Layer.PawWave` | `CL_CAT_PawWave_v01_loop_96f` | 点击猫咪 |
| 回头 | `Base Layer.LookBack` | `CL_CAT_LookBack_v02_loop_112f` | 离开前、转场、边界附近 |

Animator 参数控制：

| 参数 | 类型 | 来源 |
|---|---|---|
| `MoveSpeed01` | float | `agent.velocity.magnitude / agent.speed` |
| `IsMoving` | bool | `NavMeshAgent` 是否有速度且未到点 |
| `InFocusMode` | bool | `RecognitionSnapshot.focusState` |
| `Arousal01` | float | 识别摘要或本地规则 |

关键限制：

- `Animator.applyRootMotion = false`。
- Walk 的 XZ/Y root transform 不能推动世界位移。
- `NavMeshAgent` 和非 kinematic Rigidbody 不能同时争夺 Transform。
- 猫对象不要同时挂 `NavMeshAgent` 和 `NavMeshObstacle`。

## 6. 行为权重初始值

### 6.1 非专注

| 行为 | 权重 |
|---|---:|
| 全场巡游 `Roam` | 70 |
| 到点轻嗅 `CuriousSniff` | 10 |
| 回头 `LookBack` | 8 |
| 开心摆尾 `TailWagHappy` | 7 |
| 伸懒腰 `StretchYawn` | 5 |

非专注状态不限制猫必须在摄像头内。猫可以离开视野，但必须持续在 NavMesh 上移动，重新被摄像机看到时位置应连续。

### 6.2 专注中

| 行为 | 权重 |
|---|---:|
| 低速巡游 `FocusedRoam` | 35 |
| 安静呼吸 `IdleBreath` | 35 |
| 耳朵轻动 `EarTwitchAlert` | 18 |
| 短警觉 `AlertLook` | 8 |
| 轻摆尾 `TailWagHappy` | 4 |

专注中行为约束：

- 速度降低。
- 不强制靠近摄像机。
- 不连续播放强互动动作。
- 不弹出高打扰气泡。
- 本地规则优先于 LLM 建议。

### 6.3 用户操作

| 事件 | 动作策略 |
|---|---|
| 点击猫咪 | `PawWave` 75%，`TailWagHappy` 15%，`HeadTiltListen` 10% |
| 长按猫咪 | `HeadTiltListen` 60%，`TailWagHappy` 40% |
| 频繁点击 | 降低社交动作连发，低频 `HeadShakeNo` |
| 专注开始 | 降速，切低扰动行为 |
| 专注结束 | 可短播 `AlertLook`，再恢复非专注巡游 |

## 7. Unity 细分落地任务

| 顺序 | 任务 | 完成标准 |

| 9 | 接入兴趣点 anchors | 猫会访问广场、路口、树荫、长椅等合理区域 |
| 10 | Play Mode 验证 | 连续 3 到 5 分钟无穿模、无闪烁、无 Console error |
