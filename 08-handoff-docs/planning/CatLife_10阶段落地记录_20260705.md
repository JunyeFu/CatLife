## 阶段 1：BlueLM Unity 端接口骨架

完成时间：2026-07-05。

### 本阶段落地内容

- 新增 `LlmRuntimeMode`：定义 `Auto`、`MockOrVivoCloud`、`BlueLmOnDevice`、`LocalTemplateOnly` 四种 Unity 侧 runtime 模式。
- 新增 `LlmClientFactory : MonoBehaviour, ICatLLMClient`：未来场景可把 `CatBehaviorDriver` 的 LLM 引用切到工厂组件；当前场景仍保留 `MockCatLLMClient`，不破坏已有演示路径。
- 新增 `BlueLmUnityRequest`：统一封装 requestId、超时、system/developer prompt、去标识化用户上下文 JSON 和输出 schema。
- 新增 `BlueLmAndroidEvent`：统一解析 Android 回调成功/失败事件，并把成功输出收敛到 `LLMBehaviorSuggestion`。
- 新增 `BlueLmCallbackReceiver`：提供 `OnBlueLmEvent(string json)` 回调入口，供后续 Android 插件通过 `UnitySendMessage` 回传。
- 新增 `BlueLmOnDeviceClient : MonoBehaviour, ICatLLMClient`：Editor/非 Android 环境自动本地 fallback；Android 环境预留 `AndroidJavaClass` 桥接；超时或桥接失败不阻塞猫咪行为。
- 更新 `CatLifeRuntimeAssemblyValidator`：加入 BlueLM requestId、成功回调 JSON、失败回调 JSON 的可重复检查。

### 保留边界

- 没有引入 Android SDK、AAR、Gradle 或 Manifest 变更；这些属于阶段 2。
- 没有替换当前场景中的 `MockCatLLMClient` 引用；本机私有 vivo 云端配置优先真实 API、失败回退 mock 的路径保持不变。
- LLM 输出仍只能进入 `LLMBehaviorSuggestion` 的高层权重、短句和 `showBubble`，不新增坐标、Transform、NavMesh、Animator 命令入口。

## 阶段 3：端侧 JSON Guard 与 Prompt Builder

完成时间：2026-07-05。

### 本阶段落地内容

- 新增 `Assets/Configs/bluelm_catlife_feedback_schema.json`：
  - 固定 `version=catlife.bluelm.feedback.v1`。
  - 要求 `recommendedLocalAction`、6 个安全布尔位和行为权重字段。
  - 禁止安全布尔位为 true。
- 新增 `Assets/Configs/bluelm_unity_request_schema.json`：
  - 固定 `schemaVersion=catlife.bluelm.request.v1`。
  - 约束 `requestId`、`timeoutMs`、prompt 字段和 `userContextJson`。
  - 明确阻断 `rawText`、`packageName`、`clipboard`、`screenContent`、`x/y`。
- 新增 Android `BlueLmJsonGuard.java`：
  - `validateRequest(...)` 检查 requestId 与 `userContextJson` 隐私禁词。
  - `validateOutput(...)` 检查严格 JSON、版本、安全布尔位和输出禁词。
- 新增 Android `BlueLmPromptBuilder.java`：
  - 将 Unity request 包装为 `catlife.bluelm.prompt.v1` prompt envelope。
  - 标记 `strictJsonOnly=true` 和隐私策略。
- 更新 Android `BlueLmEngine.java`：
  - generate 前先跑 `BlueLmJsonGuard.validateRequest(...)`。
  - SDK 未接入时仍返回明确失败码，但会经过 prompt builder 生成可审计 envelope。
- 更新 Unity `LLMBehaviorSuggestion.cs`：
  - 增加 `version`、`recommendedLocalAction` 和 6 个安全布尔位。
  - 安全布尔位任一为 true 时拒绝输出。
  - 允许 `quiet` mood，并继续 clamp 权重。
- 更新 Unity `PrivacyGateway.cs`：
  - 输入侧补 `rawText`、`packageName`、`clipboard`、`screenContent`、`x/y` 等禁词。
- 更新 Unity `CatPromptBuilder.cs` 和 `CatPromptContext.cs`：
  - prompt/schema 明确 strict JSON、禁止 Markdown/解释、禁止坐标/相机/麦克风/剪贴板/包名等隐私或控制项。
- 更新 `CatLifeRuntimeAssemblyValidator`：
  - 验证两个 schema、Android guard/prompt builder、Unity 严格输出安全位和拒绝逻辑。

### 保留边界

- 本阶段没有接入真实 BlueLM generate；那是阶段 4。
- 本阶段没有构建或上传 APK；那是阶段 9。
- 本阶段没有写入任何真实 AppKEY；私有 key 仍只允许存在于本机 ignored Resources。
- Android guard 只扫描 `userContextJson`，不扫描 schema 字段名本身，避免误拒绝合法请求。
- Android output guard 只扫描 `suggestedLine` 与安全布尔位，避免误拒绝 `coordinateCommandIncluded=false` 这类安全字段名。
