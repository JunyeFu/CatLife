## 1. 版本路线

| 版本/阶段 | 定位 | 允许声明 |
|---|---|---|
| `0.3.0 (3)` | 冻结 MVP 基线 | 小镇、基础会话、记录/成长/设置骨架、会后 MiMo 单次请求、模拟器运行 |
| L1-01～L1-06 开发构建 | 内部阶段包 | 只声明已经通过的当前硬门，不称提交候选 |
| G6 通过后的新版本 | 提交候选 RC | 可进入模拟器全回归、真机和材料重制 |
| G7 通过版本 | 可提交版本 | 仅声明最终验收报告列出的能力 |

新 RC 的具体版本号在 G6 通过时确定，避免未完成时制造多个伪候选。

## 2. 总体依赖

```text
L1-01 运行架构
  -> L1-02 猫咪动作与移动
  -> L1-03 行为识别与自动专注
  -> L1-04 前端视觉还原
  -> L1-05 MiMo 可感知闭环
  -> L1-06 PPT 其余核心功能
  -> L1-07 提交候选与证据
```

每个 L1 先完成契约和测试，再修改场景/Prefab，最后进入目标运行环境验收。

## 3. L1-01 统一移动运行架构

目标：将旧 Cat、Recognition、SceneInteraction 能力接入当前移动场景，同时保持唯一会话真源。

| 中任务 | 小任务 | 产物 |
|---|---|---|
| M1.1 组件盘点 | S1.1.1 列出移动场景现有组件；S1.1.2 标记旧模块可复用/废弃入口 | 组件接线表 |
| M1.2 状态契约 | S1.2.1 冻结 Session 阶段；S1.2.2 定义 Recognition 快照；S1.2.3 定义 Cat 命令；S1.2.4 定义 UI 事件 | 状态与事件契约 |
| M1.3 场景装配 | S1.3.1 建立 Systems 根；S1.3.2 注入模块引用；S1.3.3 删除重复驱动路径 | 更新后的移动场景/构建器 |
| M1.4 基础测试 | S1.4.1 单元测试事件映射；S1.4.2 PlayMode 验证单一状态源 | G1 测试证据 |

不做：猫咪完整表现、最终 UI 美化、真实 MiMo 扩展。

退出：G1 通过。

## 4. L1-02 猫咪动作与移动系统

目标：恢复猫咪自主移动，并使四个会话状态拥有可区分的行为。

| 中任务 | 小任务 | 产物 |
|---|---|---|
| M2.1 动作资产统一 | S2.1.1 审计 FBX clips；S2.1.2 对齐动作 manifest；S2.1.3 重建统一 Animator 映射 | 10 动作 + Walk + 6 主链动作映射 |
| M2.2 移动空间 | S2.2.1 生成小镇 NavMesh；S2.2.2 配置岛边/建筑禁走区；S2.2.3 配置安全出生点 | 可行走区域与恢复点 |
| M2.3 行为系统 | S2.3.1 接入行为脑；S2.3.2 接入目的地规划；S2.3.3 设置四状态权重；S2.3.4 设置动作冷却 | 单一 Cat Behavior 执行器 |
| M2.4 场景互动 | S2.4.1 配置地标兴趣点；S2.4.2 点击猫反馈；S2.4.3 到点动作与气泡 | 可观察互动闭环 |
| M2.5 验证 | S2.5.1 动画接触检查；S2.5.2 PlayMode 导航；S2.5.3 模拟器 5 分钟观察 | G2 证据 |

实施顺序：先 Walk 与导航，再普通态漫游，再四状态行为，最后增加地标互动；不得先堆叠随机动作掩盖不能移动的问题。

退出：G2 通过。

## 5. L1-03 行为识别与自动专注

目标：以本 App 内真实操作生成连续状态谱，并提供主动和自动两种进入专注路径。

| 中任务 | 小任务 | 产物 |
|---|---|---|
| M3.1 事件采集 | S3.1.1 点击；S3.1.2 滑动；S3.1.3 停顿；S3.1.4 页面；S3.1.5 猫互动；S3.1.6 前后台 | 去标识化事件流 |
| M3.2 特征与状态谱 | S3.2.1 滑动窗口；S3.2.2 三项分值；S3.2.3 状态标签；S3.2.4 趋势 | RecognitionSnapshot |
| M3.3 自动进入 | S3.3.1 适应时长设置；S3.3.2 阈值判断；S3.3.3 可取消过渡；S3.3.4 防止重复触发 | 自动专注路径 |
| M3.4 评审可视化 | S3.4.1 实时分值；S3.4.2 状态变化；S3.4.3 数据边界说明 | 隐藏评审层 |
| M3.5 验证 | S3.5.1 纯逻辑用例；S3.5.2 PlayMode 事件；S3.5.3 模拟器复现脚本 | G3 证据 |

不做：跨 App 原始触控、屏幕内容、输入文本或应用包名采集。

退出：G3 通过。

## 7. L1-05 可感知 MiMo 闭环

目标：让用户清楚感知“聚合数据经 MiMo 生成建议，并由本地系统执行安全猫咪反应”。

| 中任务 | 小任务 | 产物 |
|---|---|---|
| M5.1 输出契约 | S5.1.1 温和提醒；S5.1.2 任务回归建议；S5.1.3 猫动作 ID；S5.1.4 来源 | 结构化结果契约 |
| M5.2 可见流程 | S5.2.1 请求中；S5.2.2 成功结果；S5.2.3 本地结果；S5.2.4 隐私详情 | AI 结果组件 |
| M5.3 动作执行 | S5.3.1 允许列表；S5.3.2 解锁检查；S5.3.3 触发动作；S5.3.4 显示动作原因 | 文案—动作闭环 |
| M5.4 验证 | S5.4.1 单次请求；S5.4.2 失败不重试；S5.4.3 UI/日志一致；S5.4.4 凭据检查 | G5 证据 |

调用时机保持“完成会话后一次”，不让模型接管计时、奖励或状态切换。

退出：G5 通过。
