# CatLife L1-01 移动运行组件接线与状态事件契约

日期：2026-09-03
阶段：L1-01 / G1 运行架构门

## 1. 本阶段边界

L1-01 只建立移动端运行骨架、单一状态所有权和事件接线，不实现完整猫咪移动、完整动作图、最终 UI 或 MiMo 可视化体验。后续模块必须接入本契约，不得另建计时器、奖励计算或并行会话状态机。

## 2. 当前组件盘点与处置

| 组件 | 当前职责 | L1-01 处置 | 后续等级 |
|---|---|---|---|

| `RealtimeFeatureEngine` | 聚合页面、触控、后台/前台、专注边界事件 | 接入唯一 `CatLifeRuntimeSystems` | L1-01 |

## 3. 运行层级

```text
CatLifeMobileApp
  ├─ reads/writes CatLifeSessionController (唯一会话状态源)
  ├─ renders serialized UI views
  ├─ drives CatLifeCameraDirector
  └─ emits phase and local UI events
          ↓
CatLifeRuntimeSystems
  └─ CatLifeMobileRuntimeCoordinator
       ├─ RealtimeFeatureEngine
       ├─ MockRecognitionProvider → RecognitionSnapshot
       └─ CatLifeMobileCatPresenter
```

`CatLifeRuntimeSystems` 不包含 `CatLifeSessionController`，`CatLifeMobileApp` 上也不挂第二个协调器。

## 4. 冻结接口

### 4.1 Session 状态输出

- 权威类型：`CatLifeSessionPhase`。
- 合法阶段：`Normal → Transition → Focus → Reward`；中断后回 `Normal`。
- 权威数据：阶段、目标结束时间、剩余时间、完成/中断记录、成长和爪印。
- 只有 `CatLifeSessionController` 可生成或修改上述数据。

### 4.2 Recognition 聚合输出

- 输出类型：`RecognitionSnapshot`。
- 输入事件：`page_enter_*`、`focus_touch`、`app_pause`、`app_resume`、专注开始、专注完成或中断。
- 只允许使用本地聚合值；不得写回 Session，也不得改变倒计时和奖励。

### 4.3 Cat 命令输入

- 阶段命令：`ApplyPhase(CatLifeSessionPhase)`。
- 快照输入：`RecognitionSnapshot`，通过 Presenter 的只读上下文更新。
- 即时表现命令：低干扰提醒、奖励庆祝、返回坐姿。
- 猫表现层不得调用 Session 的开始、完成、中断或奖励接口。

### 4.4 UI 事件输入

- 页面路由统一发出 `page_enter_<view>`。
- Focus 触控发出 `focus_touch`。
- 生命周期发出 `app_pause` / `app_resume`，是否累计后台次数仍由 Session 按当前阶段决定。
- UI 只渲染 Session 数据；页面名不是业务阶段，也不得推导奖励。
