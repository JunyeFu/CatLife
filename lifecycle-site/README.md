# CatLife 全生命周期工作台

本地地址：<http://127.0.0.1:24186>。两周计划：2026-10-08 至 2026-10-21。

## 使用

```powershell
cd D:/Agent/catlife/lifecycle-site
npm ci
npm run evidence
npm run dev
```

打开阶段，点击任务可编辑状态、负责角色、计划日期、证据与备注。日期修改同步两周视图；两周以外的任务仍在生命周期页可见。进度保存在此地址、此浏览器的 localStorage，不自动改写 Git 文件或其他浏览器。每天结束用“导出进度”保存 JSON，换浏览器后“导入进度备份”。导入替换前有确认，验收基线不可由导入覆盖。

`npm run evidence` 只复制 10 份明确列出的当前证据及已有 Noto Sans SC 字体；不复制 APK、私有配置、密钥或原始大模型。证据、字体和截图留在本地忽略目录。字体沿用现有项目 OFL 资产，公开分发前应随附许可；本工作台本轮不公开部署。

## 内容

- 10 个阶段、70 个独立交付：10 已验收、26 待验收、29 未开始、5 待决策；不将局部交付计为整个阶段通过。
- 14 个自然日计划，有负责角色、前置任务、验收标准、产物与当前证据；不是已通过的工期承诺。
- 11 项资料：6 本教材、SWEBOK 及 4 项官方指南 / 框架。只声称核验书目、目录与官方介绍，不声称通读教材。
- 10 份现有工程证据，可打开截图、报告和真实录像。
- 大厂常见职责裁剪为单项目工作流，不假定存在 10 个独立团队；不照搬任何一家公司的内部流程。

证据快照：2026-10-08。当前 APK 为 0.3.0 (3) MVP；约 83.40 MiB。不把历史 PASS、日志 played、模拟器通过分别替代当前包、真实动作可读性或真机门。原 D01–D22 缺陷表没有被本次站点工作批量改成通过。

本轮完成的是知识准备与工作台，不是正式行业调研、PRD、真实用户研究或全部生命周期工作。持续维护、下线排除；短期试运行、复盘与交接纳入。

后续任务产物核验后更新基线数据，保留实际日期与结论；不要把人工修改状态当作自动执行了测试。网站不启动 AI 调用，不收集访谈数据、不操作 Unity、不上传文件。
